# Public API reference

Import the documented public models, manager, configuration, errors, and
extension contracts from `skill_manager`. Start with
[getting started](../getting-started.md) for a runnable workflow, then use
the generated signatures below when integrating a source, registry,
discovery provider, or validator.

Skill Manager owns validation and lifecycle decisions; downstream agents,
MCP transport, and infrastructure remain application concerns.
